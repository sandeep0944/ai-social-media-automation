# AI-Powered Social Media Automation using n8n

## Overview
This project automates the process of converting articles into platform-specific social media content using AI.

## Workflow
Google Sheets → Article Summarization → Content Generation → LinkedIn/X Post Creation

## Features
- Google Sheets Trigger
- Article Summarization with Google Gemini
- LinkedIn Post Generation
- Twitter/X Post Generation
- End-to-End Automation using n8n

## Tech Stack
- n8n
- Google Gemini
- Google Sheets
- LinkedIn API
- X (Twitter) API

## How to Use
1. Import `workflow.json` into n8n.

5. Configure LinkedIn and X credentials.
